# 功能特性
数据结构：

[   {"姓名":"张三","语文": 88,"数学": 85,"英语": 74},
    {"姓名":"李四","语文": 35,"数学": 48,"英语": 64},
    {"姓名":"王五","语文": 95,"数学": 78,"英语": 82}
]

功能函数：

1、add_stu()：新增学生信息

2、get_name()：显示全部学生的信息

3、get_score()：查询某个学生的信息

4、change_score()：修改某个学生的信息

5、del_stu()：删除某个学生的信息

6、sort_score()：按总分降序显示学生信息

7、count_score()：统计各科平均分/最高分/最低分

8、main()：循环显示菜单（1 添加 / 2 显示 / 3 查询 / 4 修改 / 5 删除 / 6 按总分排序 / 7 统计 / 0 退出），按输入分发到对应函数，输入 0 则退出
