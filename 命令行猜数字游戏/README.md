# 命令行猜数字游戏

# 项目说明
这是学习计划第七天的练习小项目，只用"已经学过"的变量、条件判断、while、for、input 做一个Python 基础练习项目，经典猜数字小游戏的命令行实现。


# 目录结构
	第一周复盘日.py

# 运行方法

1、 确保已安装python基础环境

2、 ```bash
python 命令行猜数字游戏.py

# 功能特性
① 随机生成 1-100 的整数；
② while 循环让用户反复猜；
③ 用户猜错时，提示"猜大了 / 猜小了"；
④ 用户猜对则打印"恭喜你用了 X 次猜对！"并结束；
⑤ 输入 quit 则退出；
⑥ 最多猜 7 次，超过则失败并公布答案。
